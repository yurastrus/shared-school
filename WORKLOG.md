4. matplotlib backend примусово `Agg` (headless) — безпечно у web-воркері.

## 2026-07-24 — Двомовність (UK/EN) + публічний репо

англійська); репозиторій — публічний.

**Реалізовано:**
- `i18n.py`: таблиця `EN` (UI-рядки UK→EN) + `GEN` (локалізовані заголовки/описи
  карток і підписи на самих аркушах, за ключем генератора та мовою).
- `_` у context_processor тепер справжній перекладач: `uk` → джерело, `en` →
  `i18n.EN`, а для невідомих рядків (спільний site-nav) — **fallback на
  flask-babel** хоста (бо blueprint-context_processor перекриває `_` на своїх
  сторінках).
- Генератори приймають `lang`; текст на аркушах локалізовано (`arithmetic`:
  заголовок/Ім'я/Дата/ВІДПОВІДІ; `pythagoras`: заголовок/«заповнена»/«сліпа»;
  `number_line` — без тексту, мовно-нейтральний).
- Мова береться з `lang_code` у URL (`/uk/...` ↔ `/en/...`); ім'я файлу
  завантаження містить мову: `<name>_<lang>_A4.pdf/png`.
- README — двомовний (додано EN-вступ).

**Перевірено:** хаб і сторінки тем рендеряться коректно обома мовами; EN-аркуші
`arithmetic`/`pythagoras` згенеровано й перевірено візуально (PNG).
